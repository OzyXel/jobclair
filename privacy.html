Politique de confidentialité — JobClair

Dernière mise à jour : 26 septembre 2026

JobClair est une application Android d'aide à la recherche d'emploi. Elle fonctionne sans compte JobClair et privilégie le traitement local des données.

Données conservées sur l'appareil

JobClair peut enregistrer localement les critères de recherche, le profil professionnel, le texte extrait d'un CV choisi par l'utilisateur, les favoris et offres suivies, les statuts de candidature, les notes personnelles, les dates de candidature/relance/entretien, les coordonnées de contact renseignées par l'utilisateur et les préférences de l'application.

Le CV PDF, DOCX ou TXT est analysé localement. Le document et son texte ne sont pas transmis au proxy France Travail, à Emploi Territorial ou à un service d'IA distant.

France Travail

Lorsque France Travail est activé, les critères nécessaires à la recherche peuvent être transmis au proxy HTTPS JobClair hébergé sur Firebase / Google Cloud : mots-clés, commune, département, distance, type de contrat et période de publication.

Le proxy utilise l'API officielle Offres d'emploi de France Travail. Les identifiants OAuth France Travail restent dans Firebase Secret Manager. Le proxy ne reçoit pas le CV, le profil candidat, les favoris, les notes ou le suivi de candidatures.

Firebase App Check et Play Integrity

Le proxy France Travail est protégé par Firebase App Check. Les versions distribuées via Google Play utilisent Play Integrity pour vérifier l'authenticité de l'application ; les versions de développement utilisent App Check Debug. Ces services peuvent traiter les données techniques nécessaires à l'attestation de l'application et de l'appareil. Aucun contenu de CV, profil, note personnelle ou suivi de candidature n'est inclus dans le jeton App Check transmis au proxy.

Emploi Territorial et API géographique

Lorsque cette source est activée, les critères nécessaires sont transmis directement aux ressources publiques d'Emploi Territorial. JobClair peut interroger geo.api.gouv.fr avec le nom de la commune afin d'obtenir son code géographique.

Notifications et arrière-plan

Si la veille quotidienne est activée, Android WorkManager peut relancer périodiquement la dernière recherche enregistrée, y compris lorsque l'application n'est pas ouverte. Les rappels de relance et d'entretien sont planifiés localement. JobClair demande l'autorisation de notification sur les versions Android qui l'exigent.

Publicité et analytics

Cette version n'intègre ni publicité, ni SDK publicitaire, ni Google Analytics, ni outil d'analyse comportementale applicative.

Sécurité et sauvegarde

La sauvegarde applicative Android est désactivée. Les communications réseau utilisent HTTPS. Les données locales sont conservées dans l'espace privé de l'application Android.

Suppression des données

JobClair ne crée aucun compte utilisateur distant. Les données locales peuvent être supprimées en effaçant les données de l'application dans les paramètres Android ou en désinstallant l'application.
