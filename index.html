Objectif

Une interface unique pour chercher et organiser ses candidatures

L'utilisateur définit ses critères une seule fois. JobClair interroge les sources disponibles, harmonise les résultats et permet ensuite de consulter, sauvegarder et suivre les offres retenues.

01

Définir ses critères

Métier, mots-clés, localisation, rayon, type de contrat, télétravail, salaire, expérience et ancienneté de l'offre.

02

Rechercher

Les sources autorisées sont interrogées avec les critères compatibles, puis les résultats sont regroupés.

03

Comparer

Les informations essentielles sont normalisées afin de rendre les offres plus lisibles et comparables.

04

Suivre

Favoris, candidature envoyée, réponse attendue, entretien, accepté, refusé ou archivé.

API Offres d'emploi

Utilisation prévue des données France Travail

JobClair souhaite utiliser l'API officielle Offres d'emploi de France Travail afin d'afficher, dans l'application Android, les annonces correspondant aux critères saisis par l'utilisateur.

L'accès à l'API est actuellement en cours de demande. La présente page décrit l'intégration prévue avant mise en production.

Données utilisées

  • Intitulé et description de l'offre
  • Employeur lorsqu'il est communiqué
  • Localisation et lieu de travail
  • Type de contrat et durée du travail
  • Salaire lorsqu'il est disponible
  • Expérience demandée
  • Date de publication
  • Informations et lien permettant de consulter ou candidater à l'offre

Parcours utilisateur prévu

1 Saisie des critères

L'utilisateur définit sa recherche dans JobClair.

→
2 Interrogation sécurisée

JobClair transmet uniquement les critères nécessaires au service backend sécurisé.

→
3 API France Travail

Le backend interroge l'API Offres d'emploi avec les identifiants techniques protégés.

→
4 Affichage dans JobClair

Les offres sont présentées avec leur source et les informations utiles à la candidature.

À propos de France Travail Connect

JobClair n'utilise pas France Travail Connect dans sa version actuelle : aucune connexion au compte personnel France Travail de l'utilisateur n'est nécessaire pour consulter les offres via l'API Offres d'emploi.

Confidentialité

Les données personnelles restent sous le contrôle de l'utilisateur

Les critères de recherche, favoris, suivi des candidatures et éventuelles informations extraites d'un CV ont vocation à être conservés localement sur l'appareil. Le CV n'est pas transmis à France Travail.
