# JobClair — GitHub Pages

Ce dossier contient le mini-site public de présentation de JobClair.

## URL prévue

Si le dépôt GitHub s'appelle exactement `jobclair` et appartient au compte `OzyXel`, l'URL GitHub Pages sera :

https://ozyxel.github.io/jobclair/

## Mise en ligne rapide

1. Connectez-vous à https://github.com/OzyXel
2. Cliquez sur **New repository**.
3. Nom du dépôt : `jobclair`
4. Visibilité : **Public**
5. Créez le dépôt.
6. Ajoutez à la racine :
   - `index.html`
   - `privacy.html`
   - `styles.css`
   - le dossier `assets`
7. Dans le dépôt : **Settings > Pages**.
8. Dans **Build and deployment** :
   - Source : **Deploy from a branch**
   - Branch : `main`
   - Folder : `/ (root)`
9. Cliquez sur **Save**.
10. Attendez quelques minutes puis ouvrez :
   https://ozyxel.github.io/jobclair/
